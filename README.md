# 📊 Admin Dashboard

An interactive and modern Admin Dashboard built with HTML, CSS, and JavaScript. This dashboard provides a clean user interface for managing data, visualizing statistics, and handling application settings effectively.

## ✨ Features

- 📈 **Data Visualization:** Interactive charts and statistics summaries.
- 📱 **Fully Responsive:** Optimized for desktops, tablets, and mobile screens.
- 🌙 **Dark / Light Mode:** Easy toggle between dark and light themes.
- 🗂️ **Data Tables:** Structured data view for managing users, products, or orders.
- ⚡ **Interactive UI:** Smooth transitions, sidebar navigation, and user alerts.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Fonts:** FontAwesome / Google Fonts
